## এন্টারপ্রাইজ এডিশন

আপনার কোম্পানীর গোপনীয় ও কাস্টমাইজড ডেপ্লয়মেন্টের প্রয়োজন পূরণ করে:

- **ব্র্যান্ড কাস্টমাইজেশন**: আপনার কর্পোরেট ব্র্যান্ড ইমেজের সাথে নিরবচ্ছিন্নভাবে খাপ খাইয়ে নেওয়াيفية টेलরড VI/UI।
- **রিসোর্স ইন্টিগ্রেশন**: ডজন数 AI রিসোর্সের জন্য একညা কনফিগারেশন ও ব Management কর্পোরেট অ্যাডমিন PM,DdReന്ന通过 टीম کے成员দля ব্যবহার করতে পারে।
- **পারমিশন কন্ট্রোল**: সদস্য অনুমতি, রিসোর্স অনুমতি এবং নলেজ বেস অনুমতি স্পষ্টভাবে সংজ্ঞায়িত, কর্পোরেট-গ্রেড অ্যাডমিন প্যানেলের মাধ্যমে নিয়ন্ত্রিত।
- **নলেজ ইন্টিগ্রেশন**: আপনার অভ্যন্তরীণ নলেজ বেসকে AI ক্ষমতা ਨਾਲ একত্রিত করে, সাধারণ AI-এর চেয়ে আপনার কোম্পানির নির্দিষ্ট ব্যবসার প্রয়োজনের জন্য বেশি প্রাসঙ্গিক করে তোলে।
- **সিকিউরিটি অডিটিং**: সংবেদনশীল জিজ্ঞাসাগুলি স্বয়ংক্রিয়ভাবে আটক করে এবং সমস্ত ঐতিহাসিক কথোপকথনের রেকর্ড ট্রেস করে, নিশ্চিত করে AI কর্পোরেট তথ্য নিরাপত্তা মান মেনে চলে।
- **প্রাইভেট ডেপ্লয়মেন্ট**: বিভিন্ন mainstrteam প্রাইভেট ক্লাউড সলিউশনকে সমর্থনকারী এন্টারপ্রাইজ-লেভেল প্রাইভেট ডেপ্লয়মেন্ট, তথ্য নিরাপত্তা ও গোপনীয়তা নিশ্চিত করে।
- **নিরবচ্ছিন্ন আপডেট**: মাল্টিমোডাল AI-এর মতো অত্যাধুনিক ক্ষমতায় চলমান আপডেট এবং আপগ্রেড, নিরবচ্ছিন্ন নবাýন ও অগ্রগতি নিশ্চিত করে।

## আপডেট রাখুন

আপনি যদি উপরের ধাপগুলো অনুসরণ করে এক ক্লিকে নিজের প্রজেক্ট ডিপ্লয় করে থাকেন, তবে আপনি "আপডেট উপলব্ধ" সমস্যার সম্মুখীন হতে পারেন। কারণ ভারসেল ডিফল্টভাবে আপনার জন্য একটি নতুন প্রজেক্ট তৈরি করে tämän ফর্ক করার বদলে, ফলে সঠিকভাবে আপডেট ডিটেক্ট করতে পারে না।

আমরা স predecessors ধাপগুলো অনুসরণ করার পরামর্শ দিচ্ছি যাতে আবার ডিপ্লয় করতে পারেন:

- মূল রেপোসিটরি মুছে ফেলুন;
- পৃষ্ঠার ঊর্ধ্ব bang ডানদিকে ফর্ক বাটন ব্যবহার করে এই প্রজেক্টটি ফর্ক করুন;
- আবার ভারসেলে বেছে নিন এবং ডিপ্লয় করুন, [বিস্তারিত টিউটোরিয়াল](./docs/deployment/vercel-cn.md) দেখুন।

### অটোমেটিক আপডেট সক্ষম করুন

> আপনি যদি আপস্ট্রিম সিঙ্ক এক্সিকিউশনের ব্যর্থতার সম্মুখীন হন, অনুগ্রহ করে [ম্যানুয়ালি কোড আপডেট করুন](./README.md#manually-updating-code)।

প্রজেক্টটি ফর্ক করার পর, গিটহাবের সীমাবদ্ধতার কারণে, আপনাকে ফর্ক করা প্রজেক্টের অ্যাকশন পেজে ওয়ার্কফ্লোস ও আপস্ট্রিম সিঙ্ক অ্যাকশন ম্যানুয়ালি সক্ষম করতে হবে। একবার সক্ষম করলে, অটোমেটিক আপডেট প্রতি ঘণ্টায় শিডিউল করা হবে:

![অটোমেটিক আপডেট](./docs/assets/enable-actions.jpg)

![অটোমেটিক আপডেট সক্ষম করুন](./docs/assets/enable-actions-sync.jpg)

### ম্যানুয়ালি কোড আপডেট করুন

আপনি যদি তৎক্ষণা আপডেট করতে চান, আপনি [গিটহাব ডকুমেন্টেশন](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/syncing-a-fork) চেক আউট করতে পারেন যাতে ফর্ক করা প্রজেক্টকে আপস্ট্রিম কোডের সাথে সিঙ্ক করতে শিখতে পারেন।

আপনি এই প্রজেক্টটি স্টার বা ওয়াচ করতে পারেন অথবা রিলিজ নোটিফিকেশন পেতে লেখককে ফলো করতে পারেন।

## অ্যাক্সেস পাসওয়ার্ড

এই প্রজেক্টটি সীমিত অ্যাক্সেস কন্ট্রোল প্রদান করে। ভারসেল এনভায়রনমেন্ট ভেরিয়েবল পেজে `CODE` নামের একটি এনভায়রনমেন্ট ভেরিয়েবল যোগ করুন। ভ্যালু হতে হবে কমা দ্বারা আলাদা করা পাসওয়ার্ডেরように:

```
code1,code2,code3
```

এনভায়রনমেন্ট ভেরিয়েবল যোগ বা পরিবর্তন করার পর, পরিবর্তন কার্যকর করার জন্য প্রজেক্টটি আবার ডিপ্লয় করুন।

## এনভায়রনমেন্ট ভেরিয়েবল

### `CODE` (অপশনাল)

অ্যাক্সেস পাসওয়ার্ড, কমা দ্বারা আলাদা।

### `OPENAI_API_KEY` (প্রয়োজনীয়)

আপনার ওপেনএই API কী, একাধিক API কী কমা দিয়ে যোগ করুন।

### `BASE_URL` (অপশনাল)

> ডিফল্ট: `https://api.openai.com`

> উদাহরণ: `http://your-openai-proxy.com`

ওপেনএই API রিকোয়েস্ট বেস URL ওভাররাইড করুন।

### `OPENAI_ORG_ID` (অপশনাল)

ওপেনএই অর্গানাইজেশন আইডি সুনির্ধারিত করুন।

### `AZURE_URL` (অপশনাল)

> উদাহরণ: https://{azure-resource-url}/openai

### `AZURE_API_VERSION` (অপশনাল)

### `GOOGLE_URL` (অপশনাল)

### `ANTHROPIC_API_KEY` (অপশনাল)

### `ANTHROPIC_API_VERSION` (অপশনাল)

অ্যানথ্রোপিক ক্লaudio API ভার্সন।

ডিপসিক API URL।

### `HIDE_USER_API_KEY` (অপশনাল)

> ডিফল্ট: খালি

আপনি চান না ব্যবহারকারী saját API কী ইনপুট করুন, তাহলে এই মান 1 সেট করুন।

### `DISABLE_GPT4` (অপশনাল)

> ডিফল্ট: খালি

আপনি চান না ব্যবহারকারী জিপিটি-৪ ব্যবহার করুন, তাহলে এই মান 1 সেট করুন।

### `ENABLE_BALANCE_QUERY` (অপশনাল)

> ডিফল্ট: খালি

আপনি চান ব্যবহারকারী ব্যালেন্স কুয়েরি করতে পারে, তাহলে এই মান 1 সেট করুন।

### `DISABLE_FAST_LINK` (অপশনাল)

> ডিফল্ট: খালি

আপনি চাইলে URL থেকে সেটিংস পার্স করা বন্ধ করতে পারেন, এই মান 1 সেট করুন।

### `CUSTOM_MODELS` (অপশনাল)

> ডিফল্ট: খালি
> উদাহরণ: `+llama,+claude-2,-gpt-3.5-turbo,gpt-4-1106-preview=gpt-4-turbo` মানে `llama, claude-2` মডেল লিস্টে যোগ করুন, এবং `gpt-3.5-turbo` লিস্ট থেকে সরান, এবং `gpt-4-1106-preview` `gpt-4-turbo` হিসেবে প্রদর্শন করুন।

কাস্টম মডেল নিয়ন্ত্রণ করতে, `+` ব্যবহার করে কাস্টম মডেল যোগ করুন, `-` ব্যবহার করে একটি মডেল লুকান, `name=displayName` ব্যবহার করে মডেল নাম কাস্টমাইজ করুন, কমা দিয়ে আলাদা করুন।

সকল ডিফল্ট মডেল বন্ধ করতে `-all` ব্যবহার করুন, সকল ডিফল্ট মডেল সক্ষম করতে `+all` ব্যবহার করুন।

অজুর জন্য: মডেল নাম এবং ডেপ্লয়মেন্ট নাম কাস্টমাইজ করতে `modelName@Azure=deploymentName` ব্যবহার করুন।

> উদাহরণ: `+gpt-3.5-turbo@Azure=gpt35` মানে মডেল লিস্টে `gpt35(Azure)` অপশন দেখাবে।
> আপনি শুধুমাত্র অজুর মডেল ব্যবহার করতে পারেন, তাহলে `-all,+gpt-3.5-turbo@Azure=gpt35` মানে `gpt35(Azure)` মডেল লিস্টের একমাত্র অপশন হবে।

বাইটড্যান্সের জন্য: মডেল নাম এবং ডেপ্লয়মেন্ট নাম কাস্টমাইজ করতে `modelName@bytedance=deploymentName` ব্যবহার করুন।

> উদাহরণ: `+Doubao-lite-4k@bytedance=ep-xxxxx-xxx` মানে মডেল লিস্টে `Doubao-lite-4k(ByteDance)` অপশন দেখাবে।

### `DEFAULT_MODEL` (অপশনাল)

ডিফল্ট মডেল পরিবর্তন করুন

### `VISION_MODELS` (অপশনাল)

> ডিফল্ট: খালি
> উদাহরণ: `gpt-4-vision,claude-3-opus,my-custom-model` মানে ডিফল্ট প্যাটার্ন ম্যাচের পাশাপাশি এই মডেলগুলিতে ভিশন ক্ষমতা যোগ করুন (যা মডেলে " vision ", " claude-3 ", " gemini-1.5 ", ইত্যাদি কীওয়ার্ড শনাক্ত করে)।

ডিফল্ট প্যাটার্ন ম্যাচিংয়ের বাইরেও অতিরিক্ত মডেলে ভিশন ক্ষমতা যোগ করুন। একাধিক মডেল কমা দিয়ে আলাদা করুন।

### `WHITE_WEBDAV_ENDPOINTS` (অপশনাল)

আপনি এই অপশনটি ব্যবহার করতে পারেন যদি আপনি অ্যাক্সেস করার অনুমতি পাওয়া ওয়েবড্যাভ সার্ভিস এন্ডপয়েন্টের সংখ্যা বাড়াতে চান, ফরম্যাট অনুযায়ী:

- প্রতিটি এন্ডপয়েন্ট একটি সম্পূর্ণ এন্ডপয়েন্ট হতে হবে
  > `https://xxxx/yyy`
- একাধিক এন্ডপয়েন্ট ',' দিয়ে সংযুক্ত হয়

### `DEFAULT_INPUT_TEMPLATE` (অপশনাল)

সেটিংসে ইউজার ইনপুট প্রি-প্রসেসিং কনফিগারেশন আইটেম ইনিশিয়ালাইজ করতে ব্যবহৃত ডিফল্ট টেমপ্লেট কাস্টমাইজ করুন।

### `STABILITY_API_KEY` (অপশনাল)

স্ট্যাবিলিটি API কী।

### `STABILITY_URL` (অপশনাল)

স্ট্যাবিলিটি API URL কাস্টমাইজ করুন।

### `SILICONFLOW_API_KEY` (অপশনাল)

সিলিকনফ্লো API কী।

### `SILICONFLOW_URL` (অপশনাল)

সিলিকনফ্লো API URL।

302.AI API কী।

### `AI302_URL` (অপশনাল)

```
BASE_URL=https://chatgpt1.nextweb.fun/api/proxy
```

## ডেপ্লয়মেন্ট

### ডকার (সুপারিশকৃত)

```shell
docker pull yidadaa/chatgpt-next-web

docker run -d -p 3000:3000 \
   -e OPENAI_API_KEY=sk-xxxx \
   -e CODE=your-password \
   yidadaa/chatgpt-next-web
```

আপনি একটি প্রক্সির পেছনে সার্ভিস শুরু করতে পারেন:

```shell
docker run -d -p 3000:3000 \
   -e OPENAI_API_KEY=sk-xxxx \
   -e CODE=your-password \
   -e PROXY_URL=http://localhost:7890 \
   yidadaa/chatgpt-next-web
```

আপনার প্রক্সিতে পাসওয়ার্ড প্রয়োজন, ব্যবহার করুন:

```shell
-e PROXY_URL="http://127.0.0.1:7890 user pass"
```

MCP সক্ষম করুন, ব্যবহার করুন:

```shell
docker run -d -p 3000:3000 \
   -e OPENAI_API_KEY=sk-xxxx \
   -e CODE=your-password \
   -e ENABLE_MCP=true \
   yidadaa/chatgpt-next-web
```

```shell
bash <(curl -s https://raw.githubusercontent.com/KhulnaSoft/NextGPT/main/scripts/setup.sh)
```
